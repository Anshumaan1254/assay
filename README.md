# Assay

Assay independently verifies payment-gateway settlements: given a merchant's transaction ledger, a settlement report, a bank statement and a contracted rate card, it decomposes each bank credit into the exact transactions that produced it, recomputes every deduction, and reports — in rupees — any amount that cannot be explained.

## How well does it work?

[**EVIDENCE.md**](EVIDENCE.md) — accuracy measured against synthetic
settlement months with known planted discrepancies: per-class precision and
recall, value-weighted recall, false-positive money impact, calibration,
the conformal guarantee, LLM-boundary cost, and an ablation study that
prices each component. It is generated by `make evidence` from a real run
and is never hand-edited; `scripts/check_evidence.py` fails the build if it
was.

```
assay audit --run-dir runs/realistic-seed42   # audit one settlement month
assay explain PAY-000123                      # the full causal chain for one transaction
make evidence                                 # regenerate EVIDENCE.md from a real run
```
