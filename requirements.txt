# Runtime dependencies for the Vercel deployment of reviewer/api.py.
#
# vercel.json points installCommand at this file deliberately. Left to its
# own devices, Vercel's Python runtime resolves pyproject.toml with uv, and
# that install is wrong here in both directions:
#
#   - it MISSES fastapi and uvicorn, which live in the `dev`/`ui` extras
#     because the CLI is the product and must stay installable without a web
#     stack. The function would fail to import.
#   - it ADDS scikit-learn and matplotlib, which only `eval/` uses. Together
#     they are most of a serverless bundle.
#
# The list below is the AST-computed import closure of the entrypoint, which
# reaches exactly these packages:
#
#   dotenv fastapi google numpy pydantic scipy sqlalchemy sqlmodel structlog
#
# That walk also confirms the deployed app never reaches `datagen` --
# invariant 5 holds in production, not just in the test suite.
#
# Keep this in step with pyproject.toml when a runtime dependency changes.

fastapi
pydantic>=2
sqlmodel
structlog
python-dotenv
numpy
scipy
google-genai

# Build-step only: `python -m cli` loads the full Typer app, which imports
# datagen and the ingest client on the way past. Small enough not to matter.
typer
pyyaml
httpx
